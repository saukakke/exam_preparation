# System Architecture

## Principles
- Domain-Driven Design
- SOLID
- Modular monolith
- API-first contracts
- Event-driven side effects
- Queue-backed expensive work

## Domains
Identity, Organizations, Academics, QuestionBank, Examinations, Assessments, Learning, ArtificialIntelligence, Gamification, Billing, Notifications and Analytics.

## Multi-tenancy
Users are global identities. Organization membership determines tenant context and authorization.
