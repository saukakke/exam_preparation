# Identity Module

## Responsibilities
Authentication, user lifecycle, API tokens, authorization boundaries, sessions and device lifecycle.

## Current foundation
- Email/password registration
- Sanctum personal access tokens
- Login/logout
- User status enum
- Form request validation
- API resource serialization
- User factory
- Registration and health tests

## Next additions
2FA, magic links, social OAuth, device/session management, password reset, verification events and organization-scoped authorization are added as subsequent Identity increments after package installation is verified.
